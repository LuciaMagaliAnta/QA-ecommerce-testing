# E-commerce Testing Portfolio

**Project type:** Educational Manual QA practice project  
**Application:** Simulated e-commerce website  
**Testing focus:** Product filtering, shopping cart, cart counter, and purchase total.

This repository contains practice test cases created for a Junior Manual QA portfolio. The scenarios and execution results are simulated for learning purposes; they are not claims of professional production experience.

## Test case status

- `PASS`: actual result matched expected result in the stated exercise.
- `FAIL`: actual result differed from expected result in the stated exercise.
- `NOT RUN`: the test case was designed but no execution result was established.
- `PROPOSED`: an additional test scenario suggested for broader coverage.

## Environment

The exact browser, operating system, application build, and test account were not consistently recorded during the exercises. They must be filled in with real values before presenting any test execution as reproducible.

## Test cases

See the individual Markdown files in [`test-cases/`](test-cases/).

## How to use

1. Review each test case.
2. Replace any example product names or prices if your test environment differs.
3. Execute the steps in the actual application.
4. Record the real Actual Result and execution status.
5. Attach genuine screenshots or screen recordings as evidence.
6. Update this README if the scope or results change.
