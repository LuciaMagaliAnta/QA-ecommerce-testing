# QA E-commerce Testing Project

## Project Overview
This is a beginner QA portfolio project focused on testing the price filter of an e-commerce website.

## Objective
Verify that the price filter displays only available products priced at or below $1000.

## Scope of Testing
- Functional Testing
- Boundary Value Analysis
- Test Case Design
- Bug Reporting
- Retesting
- Regression Testing
- Basic SQL Validation

## Test Scenarios
- Verify that available products priced below $1000 are displayed.
- Verify that available products priced exactly $1000 are displayed.
- Verify that products priced above $1000 are excluded.
- Verify that unavailable products are excluded.

## Tools and Technologies
- Manual Testing
- SQL
- Jira (learning and practice)

## Project Status
In progress.

## Disclaimer
This is an educational QA portfolio project. Test scenarios and defect examples are used for practice and do not necessarily represent defects verified in a live application.
